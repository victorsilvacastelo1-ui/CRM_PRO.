CRM Pro

Política de Privacidade

Versão preliminar. Este texto deve ser revisado antes do lançamento comercial definitivo do serviço.

1. Dados tratados

O CRM Pro pode tratar dados cadastrais de usuários, informações de autenticação, dados de empresas e contatos inseridos pelo cliente e registros necessários à operação do serviço.

2. Finalidades

Os dados são utilizados para fornecer o CRM, autenticar usuários, manter funcionalidades contratadas, prestar suporte e proteger a operação do serviço.

3. Dados inseridos pelo cliente

O cliente é responsável pelas informações que cadastra no CRM Pro e deve possuir base legal adequada para tratar dados de terceiros conforme a legislação aplicável.

4. Segurança

São adotadas medidas técnicas e organizacionais compatíveis com a natureza do serviço. Nenhum sistema conectado à internet pode garantir risco zero.

5. Direitos dos titulares

Solicitações relativas a dados pessoais serão tratadas conforme a legislação aplicável e os canais oficiais divulgados pelo CRM Pro.

6. Alterações

Esta política poderá ser atualizada para refletir mudanças no produto, em fornecedores ou em requisitos legais.
